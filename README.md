# 毫针治疗腰痛答辩训练器

这是一个不依赖安装、不需要联网的纯 HTML + CSS + JavaScript 网页应用。

## 最简单的打开方式

1. 保持 `index.html`、`styles.css`、`core.js` 和 `app.js` 在同一个文件夹中。
2. 双击 `index.html`。
3. 系统会使用默认浏览器打开训练器。

无需安装 Node.js，无需运行 `npm install`，断网也可以使用。学习进度只保存在当前浏览器中；请勿随意清除浏览器的网站数据。

## 已实现功能

- 5 分钟自我陈述倒计时
- 25 分钟模拟答辩倒计时
- 六类题库和分类筛选
- 单轮随机且不重复抽题
- 完成文字或口头作答后才能查看参考答案
- 已掌握、不熟悉、错题标记
- 分类掌握率和薄弱知识点统计
- 浏览器本地保存学习记录

## 开发检查（普通用户无需执行）

```bash
node --check core.js
node --check app.js
node tests/run-tests.js
python3 -m http.server 8000
```
